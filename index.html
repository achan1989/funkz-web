Funkz

Funkz is a Befunge interpreter that you can run in your browser (if it supports WASM and WebGL 2). At the moment it's only usable on large screens.

  • Version 0.3.0 — Auto-cursor when editing, breakpoints, a new statistic, fix some paste bugs.
  • Version 0.2.0 — A help screen, program statistics, various quality of life improvements.
  • Version 0.1.1 — Initial release.

Some possible future enhancements:

  • Adding comments to grid cells.
  • A proper save/load system.
  • 32-bit grid values?
  • Built-in challenges or scenarios?
